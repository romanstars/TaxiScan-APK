# TaxiScan — проєкт для Google Play

Android-проєкт TaxiScan з демонстраційним інтерфейсом і початковим екраном підписки:
- Оновлена головна панель у темному стилі з індикатором радара, доходом за день, поїздками та перевіркою дозволів
- Нижня навігація до головної, калькулятора, статистики та налаштувань
- Сучасним UI (Material 3)
- Підпискою через **Google Play Billing**
- Правильним package name `ua.taximoney.taxiscan`
- Іконкою TaxiScan та банером на головному екрані
- Калькулятором чистого доходу за сумою та відстанню
- Запуском встановлених Bolt Driver, Uklon Driver та Uber Driver
- Необов'язковим локальним зчитуванням видимого тексту замовлення й сповіщень із передаванням суми/відстані в калькулятор
- Плаваючою карткою чистого доходу поверх застосунку сервісу після надання Android дозволу накладання
- Окремим екраном дозволів Android із перевіркою стану Accessibility, батареї, накладання, сповіщень, GPS та доступу до сповіщень сервісів
- Локальним журналом пропозицій, паузою запису, очищенням і копіюванням логів
- Фільтром пропозицій і окремим екраном параметрів автоприйняття, вимкненим за замовчуванням
- Ручними таймерами поїздки й статистикою прийнятих замовлень для Bolt, Uklon та Uber
- Експортом і відновленням резервної копії налаштувань у JSON-файл
- Gradle Wrapper і GitHub Actions для автоматичної збірки тестового APK

## Швидкий старт

1. Відкрийте папку в **Android Studio** (File → Open)
2. Дочекайтеся синхронізації Gradle
3. Для ручної збірки APK запустіть `gradlew.bat assembleDebug` у Windows або `./gradlew assembleDebug` у Linux/macOS.
4. Створіть підписку в Play Console:
   - Product ID: `taxiscan_premium_monthly`
   - Період: 1 місяць
   - (опційно) Free trial 3–7 днів
5. Для публікації зберіть Android App Bundle (AAB) у Android Studio.

## Перед публікацією

- Перевірте всі дозволи та заповніть Data safety відповідно до поведінки фінальної програми.
- Accessibility Service активується лише за явною згодою користувача в системних налаштуваннях; вона обробляє видимий текст лише у Bolt Driver/Uklon Driver і не зберігає його. Перед публікацією задекларуйте призначення Accessibility API у Play Console.
- Налаштуйте перевірку покупок на сервері перед тим, як надавати доступ до Premium.

Коли Bolt Driver, Uklon Driver або Uber Driver відкрито, TaxiScan читає доступний Android текст екрана й шукає суму з валютою та кілометраж. Значення передаються в калькулятор на цьому телефоні. Точність залежить від того, чи надає поточний екран або сповіщення доступний текст; якщо значення не розпізнано, їх можна ввести вручну. Інтеграцію треба перевірити на реальному телефоні й актуальних версіях застосунків.

Трекер поїздки рахує час від етапів, які водій позначив вручну. Статистика зараховує поїздку після ручного натискання «Прийняв»; суму додає, якщо останню пропозицію цього сервісу вдалося розпізнати. Таймер не підтверджує замовлення у сторонньому сервісі.

Клієнт Billing показує ціну і запускає потік покупки, але застосунок ще не є завершеним сервісом підписки.
